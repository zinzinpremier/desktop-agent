# Chat History

PlasmaLLM persists conversations to disk by default and makes them accessible from the header's history button.

## Storage location

```
$XDG_DATA_HOME/plasmallm/chats/
```

Default: `~/.local/share/plasmallm/chats/`

## File formats

The format is configured per-widget (`Configure Desktop Agent → General → History format`):

### JSONL (`chatSaveFormat = "jsonl"`, recommended)

One JSON object per line. Two line types:

```jsonl
{"_type":"meta","version":1,"created":"2026-07-31T18:42:01Z","provider":"Ollama","model":"qwen2.5:7b"}
{"_type":"api","role":"user","content":"Comment installer Ollama?","attachments_json":"[]"}
{"_type":"api","role":"assistant","content":"Voici les étapes...","tool_calls_json":"","tool_call_id":""}
{"_type":"display","role":"assistant","content":"Voici les étapes...","timestamp":"18:42:15"}
{"_type":"display","role":"user","content":"Et pour le GPU?","timestamp":"18:43:02"}
{"_type":"display","role":"assistant","content":"Pour activer le GPU...","timestamp":"18:43:21"}
```

`_type=api` lines reconstruct the LLM context (sent back to the provider on next chat load).
`_type=display` lines drive the UI rendering.

Benefits:
- Round-trip fidelity: load a chat and continue it with full context
- Attachments (screenshots/images) are re-referenced from disk
- Tool calls / tool results are preserved

### TXT (`chatSaveFormat = "txt"`)

Human-readable transcript, `[timestamp] Role: content`. Cannot be reloaded as a live chat — only as text.

```
[18:42:15] Assistant: Voici les étapes pour installer Ollama...
[18:43:02] You: Et pour le GPU?
[18:43:21] Assistant: Pour activer le GPU...
```

## File naming

Files start with the timestamp at creation: `YYYY-MM-DD_HH-MM.jsonl`.

After the **first assistant response**, the file is renamed with a sanitized title generated by the LLM:

```
2026-07-31_18-42__Installer-Ollama-avec-GPU.jsonl
```

Old `2026-07-31_18-42.jsonl` files keep the timestamp-only name — they still load and work fine.

## Auto-title generation

The first time the assistant responds in a new chat, the widget silently asks the LLM for a 2-5 word title. The prompt:

> "Reply with ONLY a 2-5 word title for this conversation. No punctuation. No quotes. No explanation. Example: 'Setup Ollama with GPU'."

The response is sanitized (lowercase, dashes instead of spaces, ASCII-safe) and used as a filename suffix. If the LLM produces something unusable, the timestamp-only name is kept.

## Sidebar / history panel

`Ctrl+K` (or the history icon in the header) opens the history sidebar:

- **Search box**: filters chats by filename + preview (live, case-insensitive substring)
- **List**: paginated by 20, sorted by mtime descending
- **Star button** on each row: pin to top
- **Context menu** (right-click): Rename, Delete, Export to Markdown, Copy path

Stars and rename are stored in sidecar files (`.stars`, `.title-override` next to the chat).

## Markdown export

The `Export to Markdown` action writes `<chatname>.md` next to the chat file, with:

- A YAML front-matter block (date, provider, model, title)
- Headings for each message (`## You`, `## Assistant`)
- Code blocks preserved
- Image attachments rendered with `![](file)` links

## Backups

To back up your chats:

```bash
tar czf plasma-chats-$(date +%Y%m%d).tar.gz ~/.local/share/plasmallm/chats/
```

To restore:

```bash
tar xzf plasma-chats-YYYYMMDD.tar.gz
```

## Migrating TXT → JSONL

TXT files are read-only history — you cannot reload a `.txt` chat as a live conversation. To migrate an old TXT chat:

1. Open it, copy the contents
2. Create a new chat in the widget
3. Paste the conversation into the new chat as a single user message prefixed with "Resume this conversation:" (the LLM picks it up as context)

There is no automatic converter because the round-trip fidelity would be lost.

## Privacy

Chat files contain everything you and the LLM said, including:
- File paths you referenced (the widget redacts your home directory as `~` before sending to the LLM, but the local file may still contain it)
- Image attachments you sent
- Tool commands you approved

Delete individual chats via the right-click menu, or use `Clear all history` in the history menu (with confirmation).
